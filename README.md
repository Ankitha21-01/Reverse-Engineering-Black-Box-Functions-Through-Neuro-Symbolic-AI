# Reverse Engineering Black-Box Functions Through Human-in-the-Loop Neuro-Symbolic AI

A Human-in-the-Loop Neuro-Symbolic AI framework that learns explainable symbolic programs from input-output examples generated by an unknown black-box system. The framework integrates Large Language Models (LLMs), Inductive Logic Programming (ILP), DeepProbLog, Prolog, and Human Feedback to automatically generate, verify, rank, and execute symbolic rules.

---

# Project Overview

Traditional machine learning models often behave as black boxes, making their decision-making process difficult to interpret. This project aims to reverse engineer the behavior of an unknown black-box function by observing only its input-output examples.

Instead of accessing the internal implementation, the framework automatically discovers symbolic rules that explain the observed behavior. The generated rules are verified, ranked, and executed using symbolic reasoning techniques, while allowing optional human feedback to improve the learning process.

This framework combines statistical learning with symbolic reasoning to produce interpretable and explainable AI models.

# Example

```text
[1,2,3]
```

## Expected Output

```text
[3,2,1]
```

Detected Problem

```text
List Reversal
```

Generated Symbolic Rule

```prolog
append([H|T],L,[H|R]) :-
    append(T,L,R).

append([],L,L).

reverse_list([H|T],R) :-
    reverse_list(T,RevT),
    append(RevT,[H],R).

reverse_list([],[]).

transform(Input,Output) :-
    reverse_list(Input,Output).
```

This project proposes a Human-in-the-Loop Neuro-Symbolic AI framework capable of learning interpretable symbolic programs directly from observed input-output examples.

The framework integrates:

- Inductive Logic Programming for symbolic learning

- Prolog for executable rule generation

The resulting symbolic programs are transparent, interpretable, and executable, making the framework suitable for explainable AI and reverse engineering research.
